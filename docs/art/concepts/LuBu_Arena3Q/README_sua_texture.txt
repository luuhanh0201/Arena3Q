Bộ file sửa texture Lữ Bố

1) LuBu_texture_lemmau_fixed.png
   - Texture đã sửa lem màu theo cách bảo thủ.
   - Chỉ vá các đốm màu be nhỏ nằm trong vùng giáp tối.

2) LuBu_texture_hientai_trich_tu_blend.png
   - Texture gốc được trích trực tiếp từ file .blend bạn gửi.

3) preview_vung_sua_overlay.jpg
   - Ảnh xem trước các vùng được phát hiện để sửa (màu xanh lá).

Cách thay trong Blender:
- Mở file .blend hiện tại.
- Vào Shading hoặc UV Editing.
- Trong node Image Texture của material, bấm Open và chọn LuBu_texture_lemmau_fixed.png.
- Kiểm tra model.
- Nếu ổn, vào File > External Data > Pack Resources để đóng gói lại texture vào .blend.
- Ctrl+S để lưu.

Lưu ý:
- Do không có Blender trong môi trường xử lý, bộ file này chưa được ghi ngược trực tiếp vào .blend.
- Nếu còn một vài vết lem cụ thể, hãy gửi thêm ảnh khoanh đúng vị trí; có thể sửa tiếp trên đúng texture này.
