# Xem trước đối màu nền Chương 1

Mở `review.html`: 3 ảnh, trái trước/phải sau, trên 512px và dưới lát lặp 128px. Nguồn, prompt và số đo ở `ArtSource/Chapter01/2D/Assets/Revision_R2`. Ảnh PNG giữ local.

Đây là xem trước sửa nguồn 2D theo render Claude, chưa nghiệm thu cảnh Unity. Đã mở từng phần để kiểm; cần render lại scene với texture mới để kiểm ánh sáng và độ dễ đọc đường. Chưa build web/APK hoặc đo FPS thiết bị.
